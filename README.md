# AI Examiner — LLM-агент, що приймає іспит з NLP
 
Вебзастосунок, у якому LLM-агент проводить усний іспит з курсу «Обробка природної мови (NLP)»
у форматі діалогу: перевіряє студента, ставить питання й уточнення, оцінює відповіді та зберігає результат.


## Задача
 
Агент виконує роль екзаменатора:
 
1. Питає в студента ім'я, прізвище та email і перевіряє його за списком студентів.
   Якщо студента немає в базі — просить перевірити дані, а за згоди реєструє як нового.
2. Обирає 3 випадкові теми з програми курсу.
3. З кожної теми ставить відкрите питання, а за потреби — уточнювальні (до 3 відповідей студента на тему).
   До наступної теми переходить, коли:
   - відповідь достатньо повна і якісна;
   - студент прямо каже, що не знає (або натискає «Не знаю / пропустити тему»);
   - рівень знань уже зрозумілий і нові питання навряд чи змінять оцінку.
4. Наприкінці показує фінальну оцінку (0–10), оцінку за кожну тему, а також відгук:
   що було добре і над чим варто попрацювати. Результат і повна історія чату зберігаються у файл.
## Інструменти агента
 
Інструменти — звичайні Python-функції (`tools.py`). Моделі вони описані через JSON Schema,
і вона викликає їх через механізм tool calling.
 
| Інструмент | Хто і коли викликає | Що робить |
|---|---|---|
| `start_exam(email, name)` | модель, коли студент назвав ім'я та email | перевіряє студента в `students.json`, записує початок іспиту в `exams_log.json`, повертає 3 теми або помилку |
| `register_student(email, name)` | модель, якщо студента не знайдено і він погодився на реєстрацію | перевіряє формат email та наявність імені й прізвища, додає студента в `students.json` |
| `get_next_topic()` | система — одразу після `start_exam` і після оцінки кожної теми | повертає назву наступної теми або `NO_MORE_TOPICS`; агент додає до результату ключові пункти теми та рубрику оцінювання (шпаргалка для моделі, студент її не бачить) |
| `record_topic_score(topic, score, comment)` | модель, коли вирішила завершити тему | зберігає оцінку 0..10 і коментар за тему |
| `end_exam(email, score, history)` | модель після оцінки всіх тем (або система, якщо модель забула) | записує результат і повну історію чату в `data/results/<дата>_<email>.json` |
 

## Захист від помилок моделі

Під час тестування модель інколи плутала порядок іспиту або ставила оцінку без відповіді студента,
тому ключові правила перевіряє код:

- **Перевірки в інструментах:** не можна оцінити тему без відповіді студента, взяти нову тему
  без оцінки попередньої чи завершити іспит до оцінки всіх тем. Помилку модель отримує як
  `{"error": ...}` і виправляє дію.
- **Обов'язкове уточнення:** після однієї неповної відповіді не можна поставити оцінку 3–8.
- **Ліміт:** після 3-ї відповіді тему примусово оцінюють.
- **Тему і фінальну оцінку дає код:** `get_next_topic` викликається автоматично,
  а оцінка в `end_exam` — середнє за темами.
- **Стійкість до збоїв API:** повтор запиту при помилках 429 і 5xx.

## Архітектура
 
Структура проєкту:
 
```
app.py          — вебінтерфейс на Gradio: провайдер, модель, API-ключ, чат, статус, завантаження результату
agent.py        — ExamAgent: цикл tool calling, підтримка провайдерів, обробка помилок API
tools.py        — інструменти та їхні JSON Schema для моделі
prompts.py      — системний промпт і привітання
data/
  students.json — список студентів
  topics.json   — теми іспиту з ключовими пунктами
  results/      — результати іспитів (створюється автоматично)
requirements.txt
```
 
### Моделі
 
Підтримуються два провайдери з OpenAI-сумісним API, тому використовується один SDK `openai`:
 
- **Groq:** `openai/gpt-oss-120b` (рекомендовано), `openai/gpt-oss-20b`, `llama-3.3-70b-versatile`
- **Google Gemini:** `gemini-3.5-flash-lite`, `gemini-3.1-flash-lite`, `gemini-3.5-flash`
Модель можна обрати зі списку.
API-ключ вводиться в інтерфейсі і в коді не зберігається.
 
## Запуск локально
 
Потрібен Python 3.10 або новіший.
 
```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # macOS / Linux
pip install -r requirements.txt
python app.py
```
 
Відкрийте http://127.0.0.1:7860, оберіть провайдера, введіть API-ключ і натисніть «Новий іспит».
